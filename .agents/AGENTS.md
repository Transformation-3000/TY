# Rules

- **Contrast Rule**: Never use dark blue backgrounds with icons in almost the same color. Always ensure high contrast (e.g. white icons on vibrant backgrounds, or dark text on light backgrounds).
- **Icon-Hintergrund-Kontrast**: Du darfst niemals ein Icon designen, das auf einem farbigen/dunklen Hintergrund liegt und dieselbe oder eine sehr ähnliche Farbe hat wie dieser Hintergrund. Icons auf farbigen/dunklen Hintergründen MÜSSEN immer weiß (#ffffff) oder stark kontrastierend sein.
